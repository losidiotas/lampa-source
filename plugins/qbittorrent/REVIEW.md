# Аудит плагина qBittorrent

Дата проверки: 2026-11-15.

Это результаты статической проверки. Статусы разделов обновляются по мере исправления проблем.

## Высокий приоритет — исправлено 2026-11-15

Все шесть проблем этого раздела исправлены. Пункты сохранены как история аудита.

1. **Возможна HTML/JS-инъекция через название торрента.**
   Название и метаданные без экранирования подставляются в HTML-шаблон, а обновление выполняется через `.html()`. Специально сформированное имя торрента может вставить произвольную разметку в интерфейс Lampa.
   Файлы: `templates.js`, `components/torrent.js`, `../../src/interaction/template.js`.

2. **Панель падает на торренте без сохранённых метаданных.**
   В `TorrentComponent` нормализуется `this.metadata`, но следующая строка обращается к исходному `metadata.title`. При `null` возникает исключение. Обработчик ошибки также не отключает индикатор загрузки.
   Файлы: `components/torrent.js`, `components/main.js`.

3. **Повторная попытка установки приоритетов файлов сломана.**
   Рекурсивный вызов `filePrio(tryNumber + 1)` теряет список файлов и приоритет. Следующая попытка падает на `ids.join()`. Ошибки поглощаются, после чего `prioritySet` безусловно устанавливается в `true` и пользователю показывается ложное сообщение об успехе.
   Файлы: `components/torrent_button.js`, `client.js`.

4. **Не поддерживаются чистые BitTorrent v2 торренты.**
   Плагин использует `infohash_v1` для команд, DOM ID, карты компонентов и базы метаданных. У чистых v2-торрентов это поле пустое, поэтому команды не работают, а несколько торрентов конфликтуют. Следует использовать поле `hash`/TorrentID.
   Файлы: `components/torrent.js`, `components/main.js`, `components/torrent_menu.js`, `components/torrent_button.js`, `client.js`, `types.d.ts`.
   Справка: <https://github.com/qbittorrent/qBittorrent/issues/18188>.

5. **Автообновления могут накладываться друг на друга и обращаться к уничтоженному экрану.**
   `setInterval(async ...)` не имеет блокировки и обработки ошибок, а запросы выполняются без таймаута. Медленный запрос может выполняться дольше трёх секунд. После закрытия панели он способен завершиться и обратиться к `this.items`, уже установленному в `null`.
   Файлы: `components/main.js`, `client.js`.

6. **Удаление торрента может сломать обновление списка.**
   Если выделен последний элемент, а удалён элемент выше него, индекс `active` не уменьшается и становится недействительным. То же возможно при удалении последнего оставшегося торрента.
   Файл: `components/main.js`.

## Средний приоритет

7. **[Исправлено 2026-11-15] На qBittorrent 5 остановленные торренты получают действие «Остановить».**
   Меню распознаёт только старые состояния `pausedDL` и `pausedUP`, тогда как qBittorrent 5 использует `stoppedDL` и `stoppedUP`.
   Файл: `components/torrent_menu.js`.
   Справка: <https://github.com/qbittorrent/qBittorrent/issues/21561>.

8. **[Исправлено 2026-11-15] При смене TMDB-метаданных старый тег не удаляется.**
   Код формирует новый набор тегов, но отправляет его через `addTags`, который только добавляет теги. В результате остаются старый и новый `movie/id` или `tv/id`, а при следующем открытии может выбираться старый. Для замены нужны `setTags` или `removeTags`.
   Файлы: `components/torrent_menu.js`, `client.js`.
   Справка: <https://github.com/qbittorrent/qBittorrent/wiki/WebUI-API-%28qBittorrent-5.0%29>.

9. **[Исправлено 2026-11-15] Проверка уже добавленного торрента может навсегда оставить экран загрузки.**
   Первый запрос выполняется без `try/finally`. Ошибка сети или ссылка `.torrent` вместо magnet приводит к исключению до `Loading.stop()`. `magnetExactTopic()` также без проверки вызывает `toLowerCase()` у отсутствующего `xt`.
   Файлы: `components/torrent_button.js`, `helpers.js`.

10. **[Исправлено 2026-11-15] Автоматически восстановленный заголовок сериала теряется после повторного открытия.**
    В кэш сохраняются только `metadata.title` и `release_date`, но TV-ответы TMDB используют `name` и `first_air_date`. Первый раз сериал отображается из ответа API, а затем загружается неполная запись из базы.
    Файлы: `components/main.js`, `components/torrent_menu.js`.
    Справка: <https://developer.themoviedb.org/reference/search-tv>.

11. **[Исправлено 2026-11-15] В качестве метаданных можно выбрать человека.**
    Используется `search/multi`, но результаты не фильтруются по `movie` и `tv`. Для единственного результата человек выбирается автоматически; сохраняется тег `person/id`, который последующее восстановление метаданных игнорирует.
    Файлы: `tmdb.js`, `components/torrent_menu.js`, `components/main.js`.

## Низкий приоритет

12. **[Исправлено 2026-11-15] Каждые три секунды запрашивается полный снимок состояния.**
    `syncMainData()` сохраняет последний `rid`, объединяет частичные обновления с локальным снимком и корректно заменяет его при `full_update`. Повторяющиеся полные ответы также поддерживаются; частота опроса следует за `server_state.refresh_interval` с минимумом 500 мс.
    Файлы: `components/main.js`, `client.js`.

13. **[Исправлено 2026-11-15] Скорость скачивания скрыта для состояния `forcedDL`.**
    Торрент в этом состоянии может активно скачиваться, но контейнер скорости включается только для точного состояния `downloading`.
    Файл: `components/torrent.js`.

14. **[Исправлено 2026-11-15] При изменении API URL может появиться дублирующая кнопка меню.**
    Изменение одного непустого URL на другой повторно вызывает `QBittorrentPlugin.show()`, а `MenuButton.show()` не проверяет наличие существующей кнопки.
    Файлы: `settings.js`, `components/menu_button.js`.

15. **[Исправлено 2026-11-15] Класс `--hide-name` не всегда удаляется.**
    Он добавляется при совпадении имени торрента и отображаемого заголовка, но при последующем расхождении удаление класса отсутствует.
    Файл: `components/torrent.js`.

16. **[Исправлено 2026-11-15] Русские подписи `StoppedUP` и `StoppedDL` перепутаны.**
    Состояние UP названо загрузкой, а DL — раздачей.
    Файл: `lang.js`.

## Проверка сборки

Сборка Rollup проходит, но сообщает о циклических зависимостях между модулями плагина. Проверки вспомогательной логики находятся в `spec/qbittorrent_helpers.spec.js`.
